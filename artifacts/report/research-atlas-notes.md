# 图鉴研究笔记（data/atlas.json，dataVersion 2026-11-20.2，第二轮）

## 1. 范围与方法
- 60 条：白身鱼 5、青背・光物 7、赤身・金枪鱼 7、其他鱼类 7、贝类 8、甲壳类 7、头足类 4、海胆・鱼卵 6、配料・调味 9。
- 来源 95 条（第一轮 73）。第二轮的核对方式改为用 curl 把页面或 PDF 下载到本地后读文字（pdftotext、HTML 去标签），不再只依赖 WebFetch 的小模型摘录。因此第二轮新增和复核过的来源，我都读过原文文字。
- 月份规则：只写来源明确支持的月份，多来源取并集；分歧写进 `season.note`；来源没写旬就留 `months: []`。共 22 条为空。
- sources 数组按 tier 排序（官方/政府 → 权威媒体 → 百科），官方/权威在前，维基在后。

## 2. 第二轮发现的第一轮错误（已修正）

## 6. 关于 omakaseRole / techniques（编辑性概括）
- `omakaseRole` 里凡属编辑性概括、非来源直述的部分，已统一使用“通常/常见/因店而异”措辞（构建时对没有这类措辞的条目自动加“通常：”前缀）。
- 来源直接支撑的角色叙述只有：nippon.com 对煮切り/ツメ/粗盐的用法与ガリ清口，北海道庁与 JETRO 对寿司种、刺身用途的叙述，日文维基对‘可作寿司种’的叙述。其余（如‘多在中后段’‘开场’）属编辑性概括。
- `techniques` 数组里没有标注来源的做法（如‘昆布〆’‘炙烧’）属行业常见做法的概括；个别条目已写明‘来源未载’。UI 建议把 omakaseRole 与 techniques 归入“编辑说明”，不与带来源的旬期等事实性字段同等展示。

## 7. 对 UI 的建议
- **季节日历**：用“浅色带 + 虚线边框”表示参考月份，不用实心填充，避免像保证。months 为空的条目放入“不以旬论 / 来源未给出”分组，并显示 note 的第一句原因。
- **免责声明**：页面顶部固定展示 `seasonDisclaimer`；条目详情里再显示该条 `season.note`，不要折叠。
- **分歧提示**：note 中含‘来源分歧/不一致’的条目（madai、ishidai、sawara、saba、kuromaguro、kohada 等）加“来源有分歧”小标。
- **来源展示**：条目底部按 tier 列出来源（官方/政府、权威媒体、百科/二手整理），百科类标“次级来源”。
- **筛选**：按 category、月份（只匹配 months 非空条目）、“不以旬论”分组；搜索覆盖 zh / ja / aliases。
- **安全提示**：生食类条目显示厚労省アニサキス页链接（来源 id `web:atlas-mhlw-anisakis`），突出‘醋/盐/酱油/芥末无效’。
- **措辞**：避免‘最佳月份’‘当季必吃’，使用‘常见旬期（参考）’。
