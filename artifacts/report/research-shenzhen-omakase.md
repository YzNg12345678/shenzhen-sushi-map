# 深圳 Omakase 研究笔记（职责 A，2026-11-20）

产出：`data/audit.json`（54 候选：include 2 / pending 21 / exclude 31）、`data/sources.shops.json`（11 条公开来源 + 1 条高德来源）。

## 1. 结论先行

- 30 篇小红书里，真正“板前 + 主厨发办 + 最低套餐 ≥300 元”且证据可追溯的只有两家：隐谷 Omakase（福田财富店）与齐武（后海）。其余要么套餐价低于 300，要么价格/板前证据不足。宁缺毋滥，主清单只给 2 家。
- 小红书中最热的一批平价店（匠龙 298、小十 299、十贯 298、寿司大 280、小志 298、半藏 290、鮨政 200+、雾 bistro 268）全部因价格门槛排除；高德人均也同向（196–295）。
- 高德人均不可靠：寿司大高德 317–376 高于套餐 280；匠龙高德 196–288 低于笔记 “480/630 档”。因此只作冲突信号。

## 2. 深圳 Omakase 的实际特点（均写入 audit.characteristics）

1. 价格带两极：平价套餐 200–300 元一大片，300+ 的板前店少且价位跨度大（368 → 498 → 640–720 → 约 2000）。
2. 出品公式同质：海胆（蛋糕/热狗/手卷）、飘雪鹅肝金枪鱼赤身、茶碗蒸，握寿司多为 6–10 贯；烧物、汁物在笔记中少见。
3. 价格透明度差：进吾 368 套餐里有加价项与三选一，评论区会纠正正文。
4. 形态多样：日法融合（chef 藤本）、板前潮菜（春海湾，按证据不算发办）、烧鸟 omakase（小火玺）、京都庭院江户前（植庭）。
5. “omakase”一词被滥用：980 元自助、680/980 寿司放题、268 元 bistro 套餐。
6. 高价店争议在服务：忌口执行失误、新客/熟客区别对待、餐量小；预约规则与一场制极少被写明。
7. 与香港对比：评论多用寿司郎或香港价位作参照，说明 300–600 元档价值判断依赖细节。笔记没有直接回答跨境交通/适合谁的问题，本研究不下此类结论。

## 3. 规则（R1–R9）与理由

R1 板前；R2 主厨发办为主；R3 一场制/预约制（加分项，缺失不排除）；R4 排除类别（按证据与类型，不只看店名）；R5 最低套餐 ≥300；R6 价格未知→pending/exclude；R7 证据最低要求（互动量不计，单源仅“低”置信度）；R8 分店逐一核对；R9 不明字段 null。

R3 设为“加分项”是有意的：现有公开来源几乎不写一场制，若设为硬门槛主清单会是 0 家。如主 session 想更严格，可把 R3 改为必要条件，则两家 include 中隐谷（R3 unknown）需降为 pending。

excludeNamePatterns 共 7 条，已用 JS 正则对所有 include/pending 店名测试，无误伤；对寿司郎、滨寿司、居酒屋、寿喜烧命中，对“鮨政·Omakase”“久·板前”“旨楽板前寿司”等不命中（后者靠价格规则处理）。

## 4. 主清单两家的审计要点

- **隐谷 Omakase（福田财富店）**：点评两页均 720 元/位，携程 640，高德 627；点评写板前位 + 两个包房，另一页写主厨按忌口/时令定制并逐贯讲解；携程写主厨来自香港。置信度“中”：评价日期未标、小红书无交叉证据、预约规则未知。携程提到 999999 元年卡，属营销噱头，已作风险写入。
- **齐武（后海）**：作者称人均约 2000，高德 1824，量级互证；提前一个月预约、大将现场握寿司。但只有 1 篇负面体验 + 评论，公开网页找不到独立来源，“黑珍珠”仅为作者自述，未核实。置信度“低”。评论区有相反体验（庆生被招待），已写入 disputes。

## 5. 待核实区（21 家）分层

- 身份较可信、缺价格：植庭寿司（三篇笔记一致，高德人均 1158/1582，缺午市/晚市套餐价）、小室 Komuro（二手指南：八席、单一菜单、需数周预约，价格未列）、小火玺烧鸟板前（单篇食记，无价格）。
- 价格有但有冲突或身份缺口：进吾渔所（368 vs 评论加价项 vs 高德 251）、旬筑（人均 300 边界、可单点）、鮨汐（498，但高德只匹配到罗湖外卖 POI，板前未证）、泽寿司（高德 254 偏低）。
- 仅高德 POI + 名称线索（证据最弱，建议主 session 仅在“动态检索”中展示，不单独做卡片）：鮨冠、禾木·鲸生、鮨毅、无味、久·板前、鮨影（皇庭）、鮨嵐、鮨吟、大阪、鮨欢、Rama 板前料理、Sushi Man；以及单一自媒体/二手聚合来源的吟隐、Sei ku。

## 6. 未解决缺口与建议

1. 植庭、小室、小火玺、进吾、旬筑、鮨汐：需要商家官方/点评套餐页的最低套餐价。
2. 齐武、隐谷：需要独立近期来源（2026 年内）确认仍在营业与价位；齐武黑珍珠身份需到官方榜单核实。
3. 一场制/定时：所有店均缺，建议预约页逐店补。
4. 搜索环境限制：WebSearch 对中文点评页返回稀疏，大众点评/小红书公开页只能抓到少量；未能访问官方榜单。聚合页 enprimeurclub 上还有 “Sushi Shizuka (Shenzhen)”（黑珍珠一钻 2026，价格档 $200–300），无法确认等于植庭寿司，故未采用；另有搜索摘要提到寿司芳（大阪米其林二星，平安金融中心），未取得可引用页面，未入库。
5. 已追加高德补查名单：星耀、新田、鮨汐、竹 TA-KE、植藤、水木、sushi man、六本木料理、北纬赤醋、鮨响满、鮨冠、隐谷、鮨毅、无味、大阪、壹方天地、藤本日法（均已回读结果并写入 amapFacts）。建议再补：寿司芳、Sei ku、小室、吟隐、鮨凡。
6. 高德分类错误较多（齐武标中餐厅、进吾渔所标垂钓园、隐谷标餐饮相关），动态检索不应依赖类型字段筛选，应以名称模式 + 价格 + 人工来源三层把关。

## 7. 对 schema 的建议（未改动）

- `price` 增加 `tiers: {name, perPerson, source}[]`，便于匠龙这类多档位店展示 480/630 档（现只能取最低价）。
- `identity.basis` 可增加 `counter / chefsChoice / oneSeating` 三个子结论，避免用 checks 文本去推断。
- `Claim.asOf` 对网页来源常缺失；建议 UI 显示来源 `accessedAt` 作回退。
- `amapFacts` 建议支持 `branches[]`，多分店品牌（匠龙、鮨政、小志）当前只能记录一家并在 note 中写其余。
