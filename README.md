# 深圳 Omakase

面向熟悉 Omakase 的高端客群的深圳精选板前清单 + 鱼种／食材／季节图鉴。无登录、无后端、无社区、无付费排序。

- **只收录可证实的真正 Omakase**：板前 / 主厨发办，且每位 ¥300 起。普通日料、居酒屋、放题、回转寿司、普通寿司店一律不进主清单；价格未知且无法核实达到 ¥300 的店只进入明确的“待核实区”（筛选依据页），不作为合格店展示。
- **逐店精细评价**：料理风格、招牌食材与技法、主厨与节奏、套餐与加点、价位与价值、座位氛围服务、预约难度、适合场景、优势、风险与争议、资料置信度与更新时间。每个字段都挂来源；没有来源支持就显示“待核实”。没有统一评分、没有总分、没有模板话术。
- **图鉴**（`/atlas/`）：可检索、按类别与月份筛选的鱼种／贝类／甲壳类／头足类／海胆鱼卵／配料条目，含日文名、旬、风味、技法、套餐角色、识别要点与来源；季节月份不是保证。
- **筛选依据**（`/audit/`）：规则、深圳 Omakase 特点研究、逐候选逐条规则结果、价格与身份证据、纳入/待核实/排除、以及本次高德动态检索被规则拒绝的条目。

## 纳入 / 排除规则（摘要，完整规则与逐店结果见 `artifacts/report/omakase-audit.md`）

1. 必须有来源描述的板前（counter）座位或师傅现场制作；仅名称含 omakase 不算。
2. 必须以主厨发办套餐为主；单点为主、三选一、自助/放题排除。
3. 每位价格 ≥ ¥300（取有来源的最低套餐价/人均下限）；任何来源明确 < ¥300 则排除；价格未知记 unknown，不得入主清单。
4. 小红书点赞/收藏/评论量不是质量证据；用户笔记只作一手体验参考，并在界面标为“用户内容”。
5. 证据不足就减少店数或标“待核实”，不编造主厨、流派、食材、价格、口碑。
6. **动态高德检索与静态清单走同一规则**（`lib/rules.ts`）：非餐饮、未经审计、命中排除/待核实候选、名称命中排除模式、或高德人均 < ¥300 的 POI 一律不进入主清单。分店必须命中该店的分店限定词，不使用单字关键词。

## 安装与启动

要求 Node.js ≥ 20，包管理器 **pnpm**。

```bash
pnpm install --frozen-lockfile
cp .env.example .env.local     # 填入下面两个高德变量，.env.local 已被 Git 忽略
pnpm dev                       # 默认端口 3417，可用 PORT 覆盖
pnpm build && pnpm start       # 生产
```

- `NEXT_PUBLIC_AMAP_JS_KEY`：高德 JS API 2.0 Key
- `NEXT_PUBLIC_AMAP_SECURITY_JS_CODE`：对应安全密钥

`NEXT_PUBLIC_*` 在构建时内联，修改后需重新构建。详见 `docs/amap-config.md`。**不要提交或截图真实凭据。**

GitHub Pages 预览：`GITHUB_ACTIONS=true` 时 `next.config.ts` 切换为静态导出并带 `basePath`；页面是纯客户端，数据是 import 的静态 JSON，可直接部署，但构建环境需提供上述两个变量，高德控制台需放行对应域名。

## 隐私

- 个人收藏 / 去过 / 备注只存在本浏览器 localStorage（键 `shenzhen-omakase-map:v2`），不上传；唯一外部请求是高德 JS API。
- 设置里可 **导出 JSON**、**导入 JSON**（先校验，失败不改动现有数据，导入前自动留备份）、**清空**（二次确认）。清缓存/换浏览器会丢失数据，请定期导出。
- 旧版“深圳寿司地图”的本地数据（`shenzhen-sushi-map:v1`）在新键为空时会迁移其收藏/去过/私人备注，旧键保持不动。
- 因为 JS Key 会内联到前端，必须在高德控制台配置来源白名单。

## 已知限制

- 主清单只有通过身份与价位双重证据的店，数量少是刻意的；大量候选停在“待核实”，缺口（官方套餐价、板前座位描述、一场制规则）列在审计报告里。
- 大众点评店铺页与官方榜单（黑珍珠、米其林）无法公开读取，公开来源以媒体、携程、OpenRice 等可读页面为主；多数评价来源日期不明，资料置信度已据此给出。
- 高德人均是平台口径，可能与套餐价不同，只作事实字段与价格冲突信号。
- 图鉴 57 条：每条至少有一个政府/渔业主管部门/权威出版物类一手来源，旬月份只采用一手来源；个别条目（鳥貝、烏賊、数の子、煮切り、赤酢）来源只覆盖资源/加工叙述，风味与技法写“来源未载”，不作断言。部分非月份的识别/用法叙述仍引用日文维基（来源层级标“百科/二手整理”）。行业机构类来源为 0。月份不是保证，以店家当日仕入为准。
- 所有纳入店的一场制/预约规则缺第二来源，对应检查项为“待核实”而非通过；隐谷的价格来源为 2021–2022 年，穗为 2024 年，界面会醒目标注来源日期与时效风险。
- 高德检索有限流，偶尔部分检索失败（页面会提示）；E2E 依赖真实高德网络与额度。
